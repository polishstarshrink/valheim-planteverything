## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **All Crops** | Plant any seed, berry, mushroom or sapling with the cultivator |
| **Grid Snapping** | Snap plants to evenly spaced grid for clean organized farms |
| **Custom Spacing** | Configure gap between plants per crop type |
| **Yield Config** | Adjust harvest amounts and growth times per plant |
